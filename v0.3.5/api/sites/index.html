Custom Sites Reference

Sites are plain identifiers by default (ordinary commuting/bosonic degrees of freedom). This page documents the machinery for tagging a site with different commutation relations – the built-in fermion/FermionSite tag, and the AbstractSite/ ExchangeStyle trait interface it is built on, which a custom site type can also implement.

Fermionic Sites

OperatorAlgebra.fermion — Function
fermion(site)
fermion(op::AbstractOp)

Tag site, or every site an operator acts on, as fermionic (see FermionSite). Applying it to an OpChain/OpSum tags every factor or term, since a physical fermionic site must be tagged consistently everywhere it appears.

Examples

c_dag = fermion(Op(RAISE, 1))
c = fermion(Op(LOWER, 2))
n = normal_order(c_dag * c)  # picks up the Jordan-Wigner sign automatically

See also: AbstractSite, ExchangeStyle, mapsites

source
OperatorAlgebra.FermionSite — Type
FermionSite{Tid} <: AbstractSite{Tid}

Tags a site as fermionic: operators on it anticommute with operators on other fermionic sites, via the Jordan-Wigner sign matrix PAULI_Z (so its local Hilbert space must be 2-dimensional, occupied/empty).

Construct via fermion rather than calling the constructor directly.

The Site Interface

OperatorAlgebra.AbstractSite — Type
AbstractSite{Tid}

Abstract base type for site wrappers that tag a raw site identifier (of type Tid) with non-trivial commutation/exchange behavior (e.g. fermionic anticommutation).

Two sites are the same site iff they have the same concrete type and wrap isequal raw identifiers, so a physical site must be tagged the same way everywhere it appears.

fermion(1) == fermion(1)  # true
fermion(1) == 1           # false

Interface

Subtypes must implement:

  • rawsite(s): the underlying plain site identifier
  • rawsite(f, s): s with its raw identifier mapped through f. Only needed for a site carrying data besides the identifier; otherwise T(f(rawsite(s))) is the default.

A subtype is Fermionic by default. One with different (or no) special statistics overrides exchange_style, site_parity and/or exchange_phase.

See also: fermion, ExchangeStyle

source
OperatorAlgebra.rawsite — Function
rawsite(s)
rawsite(f, s)

Return the plain site identifier underlying s: s itself for a bare site, the wrapped identifier for an AbstractSite.

The two-argument form relabels instead: it applies f to the raw identifier and puts the tag back around the result.

rawsite(fermion(1))              # 1
rawsite(x -> x + 1, fermion(1))  # fermion(2)
rawsite(x -> x + 1, 1)           # 2
rawsite(identity, s) == s        # for every site

Exchange Statistics

OperatorAlgebra.ExchangeStyle — Type
ExchangeStyle

Trait describing how operators on a site behave under exchange. Two styles exist:

  • Commuting: operators on this site commute with operators on every other site – the ordinary case, and the default for any bare site identifier.
  • Fermionic: each local basis state is even or odd (site_parity), and odd components pick up a phase when they cross odd components elsewhere.

See also: exchange_style, AbstractSite

source
OperatorAlgebra.Commuting — Type
Commuting <: ExchangeStyle

Operators on this site commute with operators on all other sites. See ExchangeStyle.

source
OperatorAlgebra.Fermionic — Type
Fermionic <: ExchangeStyle

The site's local basis states each carry a parity (site_parity), and its odd component contributes exchange_phase when something is reordered across it. See ExchangeStyle.

source
OperatorAlgebra.exchange_style — Function
exchange_style(site) -> ExchangeStyle

Return the ExchangeStyle of site. Bare identifiers are Commuting; AbstractSite subtypes default to Fermionic, and declare exchange_style(::MySite) = Commuting() to opt out.

source
OperatorAlgebra.exchange_phase — Function
exchange_phase(site) -> Number

The phase the odd component of site contributes when another operator crosses it; even components contribute none. The phase belongs to the site being crossed, not to the operator crossing it.

exchange_phase(1)           # 1   -- Commuting
exchange_phase(fermion(1))  # -1  -- Fermionic

Override it for other single-species statistics, e.g. exchange_phase(::MySite) = im.

See also: ExchangeStyle, site_parity, exchange_string

source
OperatorAlgebra.exchange_string — Function
exchange_string(site, dim::Int) -> AbstractMatrix

The string an odd operator drags across site when it is embedded into the full Hilbert space – the site's parity operator, diagm(exchange_phase(site) .^ site_parity(site, dim)). atsite places it on the sites preceding the operator (single-sided Jordan-Wigner).

exchange_string(1, 2)           # I(2)
exchange_string(fermion(1), 2)  # PAULI_Z

See also: ExchangeStyle, site_parity, atsite

source
OperatorAlgebra.site_parity — Function
site_parity(site, dim::Int) -> Vector{Int}

Parity (0 = even, 1 = odd) of each of the dim local basis states of site, from which exchange_string is built.

site_parity(1, 3)           # [0, 0, 0]  -- Commuting sites are all even
site_parity(fermion(1), 4)  # [0, 1, 0, 1]  -- occupation-number parity

See also: ExchangeStyle, exchange_phase, exchange_string
